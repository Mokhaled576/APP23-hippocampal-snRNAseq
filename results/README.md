# Results

Version-controlled result tables should be stored here as CSV/TSV files. Large serialized R objects (`*.rds`) are excluded by `.gitignore`.

Primary result groups:

- pseudobulk edgeR APP23-vs-WT results for each age × broad neuronal subtype
- GO Biological Process GSEA tables
- TF activity differential-testing tables
- CellChat pathway/interaction summaries
- integrated biological summary

Final summary tables produced during the project include `pathway_remodeling_summary.csv`, `CellChat_Cholesterol_Desmosterol_summary.csv`, and `integrated_biological_summary.csv`.

Do not regenerate numerical tables from narrative summaries for repository deposition. Commit the exact CSV outputs generated by the final R workflow so that the repository preserves full precision and provenance.
